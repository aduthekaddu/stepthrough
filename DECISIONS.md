# Decisions

One line each: date, decision, reason. Newest last.

- 2026-11-15: Working product name "Stepthrough" (the repo folder name); "Groundwork" stays in the spec as its original placeholder. Reason: the owner created the folder with this name; one constant changes it.
- 2026-11-15: Biome for lint and format (spec §2 lets us pick). Reason: one fast tool instead of ESLint plus Prettier; Next 16 removed `next lint` anyway.
- 2026-11-15: Content layer is `@next/mdx` with `remark-frontmatter` and a small Zod-validated frontmatter reader, not Velite. Reason: Velite has an open Turbopack build race (zce/velite#408) and bundles Zod 3; the plain setup passed a static-export spike.
- 2026-11-15: Repo TypeScript is 7.0.2; the browser sandbox pins typescript@6.0.3. Reason: TS 7 ships no JavaScript compiler API (its package exports only version info), and the sandbox needs `transpileModule` and `createProgram` in a Worker. Next 16.4.6 and `tsc` both type-check correctly with 7.0.2.
- 2026-11-15: Trace state (stack, environment records, TDZ, heap) is generated by engine262 at build time; only narration is hand-written. Reason: spec §6.1's final-console check passes traces whose intermediate states are wrong; a spike read real hoisting, TDZ and closure state from the engine.
- 2026-11-15: The two-session transaction view is a scripted interleaving labelled as simulated, with correctness checked against real Postgres in CI. Reason: PGlite has one exclusive connection (measured: a second query waits for the open transaction).
- 2026-11-15: Resume claim changes from "CI verifies every trace against real execution" to "traces generated by a spec-compliant engine and differentially tested against Node and Chromium". Reason: Python Tutor and JS Visualizer 9000 already run real engines, so the original claim is not new.
- 2026-11-15: Lessons follow the pedagogy recipe (research/pedagogy.md §4): 8 to 12 predictions per lesson spread through it (spec §5 said 2 to 4 checkpoints after the model), confidence on every prediction, a misconception registry, and a vocabulary rule. Reason: prediction with immediate feedback and segmenting have the strongest evidence; animation alone adds little.
- 2026-11-15: Drafts are visible to the learner with a "draft" label; only the learner sets `reviewed`. Reason: spec §9.8 hid drafts from the path, but the learner reviews a lesson by studying it.
- 2026-11-15: Design palette corrected for WCAG AA (docs/design.md): light heap #906922, dark stack #5886D0, macrotask #B46CAC, error #E25850, microtask #269486, network #5F9332, plus accent-ink and accent-fill. Reason: five spec colours fail contrast; every concept also gets a label, lane and shape for colour-blind readers.
- 2026-11-15: First slice traces synchronous code only; event loops, async jobs and generators come with their lessons. Reason: independent review showed those need separate capture work and host models.
- 2026-11-15: Every lesson snippet runs as a classic script (sloppy mode, top-level var on the global object): `node -e` in content-check, indirect eval in the browser sandbox, `evaluateScript` in the trace generator. Reason: modules and CommonJS files change global-object behaviour (measured: `var x` is not on `globalThis` in a .cjs file), so lessons about scope would otherwise show different output in different places.
- 2026-11-15: Colour tokens are one `light-dark()` pair each, with `color-scheme` switched by `data-theme`. Reason: one place per token instead of three copies; behaviour matches the media-query rule in docs/design.md.
- 2026-11-15: Glossary terms live in one file per lesson (`content/glossary/<lesson-id>.yaml`), and `content/glossary.yaml` is also read. Reason: lessons are written in parallel, and separate files avoid edits to one shared file.
- 2026-11-15: A Predict's first commit is final; its feedback is re-derived from the lesson text on each render. Reason: the committed guess is the learning event, and re-answering would hide the miss from review.
- 2026-11-15: One `Diagram` with three views (`scope`, `memory`, `both`) replaces separate MemoryDiagram, CallStack and EnvChain components. Reason: the combined view draws [[Environment]] arrows from heap boxes to records, so all lanes need one coordinate space from one layout function.
- 2026-11-15: Lesson example names are unique across all lessons (`<Viz example="closure-counter">`); visualizer fixtures use `fixtures/<name>`. Reason: `Viz` gets no lesson path from MDX; the trace build fails on a duplicate name.
- 2026-11-15: A step without authored narration gets a sentence derived from the frame diff. Reason: every step needs a transcript for the live region; authored lines from `narration.yaml` still win.
- 2026-11-15: The stepper ruler is a native range input with decorative ticks behind it. Reason: it brings dragging, arrow keys, Home/End and screen reader support without custom pointer code.
